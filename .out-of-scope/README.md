# Out of scope

This folder holds permanent, linkable answers to features the maintainer has decided not to build, so the debate isn't re-run every time someone asks.

Add a file here when a request is declined for a reason that will come back: the next person to ask should get a link, not a re-litigation. Each file states the rejected feature, why it's out of scope, the escape hatch that already covers the underlying need, and any prior issue numbers (or "None filed yet.").

Don't add a file for a one-off "not now" with no durable reasoning behind it; that's just a comment on an issue.
